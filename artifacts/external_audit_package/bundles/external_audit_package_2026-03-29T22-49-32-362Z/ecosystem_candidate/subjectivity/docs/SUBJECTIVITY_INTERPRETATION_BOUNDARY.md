# Subjectivity Interpretation Boundary

## Boundary

- framework-internal only
- not externally validated
- not equivalent to human subjectivity
- not phenomenality closure
- not metaphysical closure
- not automatic corpus confirmation
- not claim-facing promotion

## SRT-6 specific rule

SRT-6 establishes only:

- seven internal coordinate surfaces with executable runtime estimators
- a multiplicative `Phi_subj`
- a conjunctive `Gamma_subj`
- provisional local and global thresholds
- lineage-based drift invalidation
- an internal support taxonomy
- ecosystem summaries across run, condition, batch, and campaign levels
- candidate-facing and audit-facing subjectivity summaries that remain
  framework-internal only

SRT-6 does not establish:

- external validation
- human equivalence
- phenomenality
- ontological superiority
- claim closure
- public corpus confirmation from runtime support
- any automatic transfer from candidate inclusion to claim-facing statements

## Reading rule

If comparator support is missing, intervention stability is weak, a coordinate is
missing, lineage drift is present, or ecosystem packaging is stale, the SRT-6
result must be read as unsupported, invalidated, or insufficient rather than as
a positive subjectivity result.
