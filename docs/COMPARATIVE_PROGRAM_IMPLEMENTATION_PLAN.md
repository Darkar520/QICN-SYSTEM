# Comparative Program Implementation Plan

## Role of Stage 2

Stage 2 is the comparative expansion layer that follows `BPF-M3` internal bridge
closure and precedes any external adjudication or metaphysical consequence analysis.

Its three subprograms are not independent:

- Human Comparator Program
- Human Equivalence Program
- Cross-Substrate Expansion

They form a single comparative stack.

- objective

- modules
  - comparative registries, surface policy loader, artifact registry, opening verifier.
- artifacts
  - none emitted by design.
- verifier
