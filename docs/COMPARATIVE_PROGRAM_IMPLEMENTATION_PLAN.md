# Comparative Program Implementation Plan

## Role of Stage 2

Stage 2 is the comparative expansion layer that follows `BPF-M3` internal bridge
closure and precedes any external adjudication or metaphysical consequence
analysis.

Its three subprograms remain one stack:

- Human Comparator Program
- Human Equivalence Program
- Cross-Substrate Expansion

## Stage2-0: comparative opening and governance

- objective
  - define ontology, ladders, boundaries, surface restrictions, and schema contracts.
- status
  - completed.

## Current state

`Stage2-0`, `Stage2-M2`, and `Stage2-M3` are now implemented. Actual human-side measurement
channels and counterpart artifacts remain absent, so the comparative program is
contract-operationalized but still bounded and non-adjudicative.
