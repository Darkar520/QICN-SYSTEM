# Comparative Program Implementation Plan

## Role of Stage 2

Stage 2 is the comparative expansion layer that follows `BPF-M3` internal bridge
closure and precedes any external adjudication or metaphysical consequence
analysis.

Its three subprograms remain one stack:

- Human Comparator Program
- Human Equivalence Program
- Cross-Substrate Expansion

## Current state

`Stage2-0`, `Stage2-M2`, `Stage2-M3`, and `Stage2-M4` are now implemented. Actual
human-side measurement channels and counterpart artifacts remain absent, so the
comparative program is now internally closed enough to decide that `Stage 3`
still may not open yet. The layer remains non-adjudicative, non-equivalence-
claiming, and non-Paper-10-authorizing.
