# Execution Pilot Packaging

Stage3-3 defines what a future execution-pilot package must contain before any
collection session or dry-run can open.

## Required package families

- package manifest
- execution session manifest
- collection session schema
- reproducibility package skeleton
- negative-control bundle skeleton
- matched-intervention bundle skeleton
- source-target pairing manifest for transport-sensitive routes

## Packaging boundary

The package may be fully defined while:

- collection sessions remain unstarted;
- datasets remain absent;
- reviewer selection remains unstarted;
- adjudicator assignment remains unstarted; and
- pilot execution remains dry-run only.

## Interpretation discipline

Package readiness is not evidence and not adjudication.
