# First Admissible Collection Unlock Map

Stage3-6 does not start collection. It only opens a controlled pre-evidential
surface.

## Still required before first admissible collection

- real reviewer selection;
- real adjudicator assignment;
- real blinding assignment;
- externally filed or locally approved preregistration as required by the
  route;
- explicit operator authorization;
- explicit collection-start command;
- contamination-free session start;
- first populated collection-log event;
- first admissible dataset-population event;
- first reproducibility-package population event.

## Interpretation boundary

This map is descriptive only. It is not a collection-start event.
