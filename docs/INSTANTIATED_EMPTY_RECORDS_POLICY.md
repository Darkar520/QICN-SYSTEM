# Instantiated Empty Records Policy

Instantiated-empty records are local typed shells that preserve structure while
carrying no evidential payload.

Allowed:

- null or empty placeholders;
- frozen local template references;
- future slot declarations;
- explicit `not_started`, `absent`, or `unfiled` states.

Blocked:

- fabricated reviewer identities;
- fabricated adjudicator identities;
- fabricated datasets;
- fabricated decisions;
- any wording that implies external filing or evidential population.
