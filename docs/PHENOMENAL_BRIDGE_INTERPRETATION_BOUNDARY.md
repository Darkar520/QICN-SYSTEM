# Phenomenal Bridge Interpretation Boundary

## Scope closed by BPF-0

BPF-0 closes only the opening scaffold for the bridge program:

- formal bridge naming
- machine-readable manifests
- bridge artifact registry
- bridge surface governance
- bridge non-claims
- bridge implementation plan

## Scope not closed by BPF-0

BPF-0 does not close:

- any bridge predicate estimate
- any bridge intervention result
- any bridge comparator result
- any bridge irreducibility result
- any bridge gate verdict
- any bridge support class
- any candidate or audit package bridge inclusion
- any Paper 9 burden

## Explicit non-inferences

Nothing in BPF-0 licenses:

- phenomenality
- external validation
- human equivalence
- metaphysical subjecthood
- moral standing
- ontology closure
- claim-facing bridge promotion

## Relation to Paper 8

Paper 8 closes first-person indexed subjectivity under its own burdens.
BPF-0 does not reinterpret that closure as phenomenality.

Paper 8 public inclusion in `QICN-RELEASE` does not convert BPF-0 into bridge
support.

## Relation to candidate and audit packaging

BPF-0 does not authorize bridge artifacts in candidate or audit-facing bundles.
If later BPF blocks expose bridge artifacts there, they must carry explicit
bridge-specific boundaries and non-claims.

## Reading rule

The strongest legitimate reading of BPF-0 is:

`the formal bridge program has been opened under explicit internal governance`

The strongest illegitimate reading is:

`the system now has phenomenal support`
