# Reproducibility Package Skeleton

The reproducibility shell required for Stage3-3 and later execution must
support reconstruction of protocol state without pretending that results or
datasets already exist.

## Minimum contents

- preregistration reference slots
- protocol version slots
- lineage and hash slots
- dataset slot declarations
- control bundle slot declarations
- statistical-shell slot declarations
- reviewer and adjudicator governance slot declarations
- failure and inconclusive pathway slots

## Current boundary

The skeleton is defined but unpopulated. A defined shell is not a populated
reproducibility package.
