# Reviewer Independence Protocol

Primary manifests:

- `docs/reviewer_independence_protocol.v1.json`
- `docs/adjudicator_independence_criteria.v1.json`
- `docs/reviewer_selection_criteria.v1.json`
- `docs/conflict_of_interest_policy.v1.json`
- `docs/blinding_policy.v1.json`

Stage3-2 hardens the reviewer/adjudicator layer into a typed governance surface.
It remains non-result-bearing.

The layer now defines:

- reviewer role classes
- adjudicator role classes
- independence requirements
- conflict classes
- disqualifiers
- blinding classes
- unblinding rules
- decision-authority boundaries
- failure and inconclusive pathways

Interpretation boundary:

- reviewer criteria defined
- reviewer selection not started
- adjudication execution not open
- no decision record exists
