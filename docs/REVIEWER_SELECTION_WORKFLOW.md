# Reviewer Selection Workflow

Stage3-3 upgrades reviewer governance from abstract independence criteria to a
typed selection workflow package.

## Workflow stages

1. define reviewer role classes;
2. define minimum qualifications;
3. collect conflict disclosures on the template surface;
4. classify disqualifiers;
5. assign blinding class;
6. prepare but do not instantiate the reviewer package.

## Required reviewer role families

- method reviewer
- statistical reviewer
- artifact-lineage reviewer
- admissibility-and-control reviewer

## Current boundary

The package may be ready while reviewer selection remains not started.
Readiness is not selection. Selection is not review. Review is not adjudication.
