# Subjectivity Runtime Protocol

This document records the Subjectivity Runtime Layer at SRT-6.

## What this layer is

- a runtime-facing implementation boundary derived from Paper 8
- a governed partial runtime path for all seven Paper 8 coordinates
- an internal gate closure over those seven coordinates with explicit
  non-compensation and drift invalidation
- an ecosystem-facing hardening layer that integrates run-level subjectivity
  outputs into condition, batch, campaign, candidate, internal-bundle, and
  audit-facing summaries without changing their semantic boundary
- framework-internal only

## What this layer is not

- not external validation
- not externally validated
- not human-subjectivity equivalence
- not phenomenality closure
- not metaphysical closure
- not claim-facing promotion

## Reading rule

`Gamma_subj` and `Phi_subj` are internal runtime objects only. A passing
internal gate means only that the currently implemented SRT-6 artifacts satisfy
the provisional internal burden under clean comparator support, intervention
stability, no drift mismatch, and ecosystem-level bundle integrity. Candidate
or audit-package inclusion means only that the layer is implemented,
internally-supported, bundle-pinned, and audit-readable. It does not mean
validated subjectivity in the external or phenomenal sense.
