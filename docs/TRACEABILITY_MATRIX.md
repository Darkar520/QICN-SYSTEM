Normalization used below:

- `Evidence class`: `direct_signal`, `derived_proxy`, `invariant`, `claim_projection`, `gate`, `batch_control`
- `Evidence scope`: `runtime_primary`, `runtime_derived`, `batch_primary`, `batch_derived`, `external_frozen`, `mixed`
- `External dependency`: `none`, `frozen_canon`, `prereg_config`, `external_service`, `legacy_input`, `human_interpretation_required`, `mixed`
