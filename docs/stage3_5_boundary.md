# Stage3-5 Boundary

Stage3-5 is a rehearsal-ready, instantiated-empty, non-evidential state only.

It means:

- provenance has been reconciled honestly;
- empty typed records exist locally;
- candidate pools and assignment stubs exist as non-filled structures;
- a rehearsal kit and dry-run sequence exist;
- the system can check operational readiness for a future pilot.

It does not mean:

- real data collection;
- admissible evidence;
- reviewer action;
- adjudicator action;
- adjudication result;
- Paper 10 final authorization;
- public release promotion.
