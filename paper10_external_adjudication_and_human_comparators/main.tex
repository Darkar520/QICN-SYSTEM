\section{Human Comparator Protocol Architecture}

The comparator architecture is organized around seven channels:

\begin{enumerate}
\item self-report;
\item intervention response;
\item temporal structure;
\item valence topology;
\item embodiment boundary;
\item ambiguity load;
\item transport preservation.
\end{enumerate}

Each channel requires a human-side artifact family, a matching machine-side
artifact family, an admissibility burden, a homologation target, matched
controls, and a failure-mode registry.

\section{Evidence Admissibility Grammar}

Admissible evidence classes include reviewer reports, preregistered human
comparator datasets, matched intervention datasets, negative-control datasets,
replication logs, statistical analysis reports, conflict-of-interest
statements, reproducibility packages, failure reports, and inconclusive
reports. Internal runtime artifacts, synthetic human data, undocumented manual
judgments, and Paper 9 publication alone are invalid substitutes.

\section{Negative Controls and Failure Modes}

The future adjudication program must preserve explicit negative controls for:

\begin{itemize}
\item channel aliasing;
\item synthetic-human substitution;
\item unblinded reviewer drift;
\item post-hoc threshold selection;
\item cherry-picked comparison windows;
\item source-only transport narratives.
\end{itemize}

\section{Preregistration Requirements}

No later comparative execution should be treated as adjudicative unless the
collection routes, channel family, estimators, thresholds, control conditions,
and failure criteria are preregistered before data collection.

blinding disclosure, or artifact bindings are inadmissible.
